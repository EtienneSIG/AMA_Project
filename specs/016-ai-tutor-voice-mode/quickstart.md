# Quickstart — AI Tutor Write/Explain + Voice Discussion

**Feature**: `016-ai-tutor-voice-mode` | **Date**: 2026-06-26

## 1. Write/explain mode (text)
Type a question → structured, AI-labelled, content-safety-scanned answer; ask a follow-up (context kept).

## 2. Voice discussion mode (voice-to-voice)
Switch to discussion → speak → see a **live transcript** → hear the spoken answer with the **identical** transcript
displayed. Continue the conversation by voice (context maintained).

## 3. EU residency + retention
Confirm STT/TTS run in an **EU region**; raw audio is **not** persisted beyond session need; transcripts follow the
minimal-retention policy; audio is **not** used for training/advertising.

## 4. No Art. 5 inference
Confirm (design + config) there is **no** emotion recognition or speaker biometric identification.

## 5. Under-16 voice consent
As an under-16 learner without parental voice consent → voice mode **disabled** (clear message); text mode available.
After parental consent → voice activates. Teacher disables voice for the class → only text offered.

## 6. Safety, escalation, mic control
- Distressing/safeguarding content → routed to the teacher escalation inbox.
- Exit/mute → mic capture stops immediately with a clear on/off indicator.

## Acceptance checklist
- [ ] Both modes available; transcript parity 100% (SC-001).
- [ ] 100% EU speech processing; 0 training/advertising use (SC-002).
- [ ] 0 under-16 voice without consent (SC-003).
- [ ] 0 emotion/biometric inference (SC-004).
- [ ] 100% exchanges logged + teacher escalation reachable (SC-005).
- [ ] Voice round-trip ≤ 2 s p50 (SC-007).
