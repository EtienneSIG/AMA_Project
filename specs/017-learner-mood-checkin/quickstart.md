# Quickstart — Learner Mood Check-In & Well-Being Routing

**Feature**: `017-learner-mood-checkin` | **Date**: 2026-06-26

## 1. Daily check-in (self-report, optional)
On the learner home page, see an optional, skippable mood prompt (happy / medium / sad) in the learner's theme/language.
Select one → supportive acknowledgement; or skip → no nagging.

## 2. Sad reason follow-up
Select "sad" → exactly three options appear (personal reasons / course difficulty / a classmate) + skip. Selecting one
records the reason and shows a supportive message + a "talk to a trusted adult" path.

## 3. Parent alert (consent-gated)
With active consent, the linked parent sees a gentle well-being notice + "how to help" guidance for sustained low mood
— framed as self-reported, **not** a diagnosis. Without consent → no surfacing.

## 4. Teacher view + recommendations
Teacher sees per-learner + aggregate self-reported mood + reason categories. When several learners cite "course
difficulty" on a topic → a pedagogically-reviewed recommendation (e.g., catch-up); teacher accepts/adjusts/dismisses.

## 5. Safeguarding routing
A "classmate" reason appears **only** in the teacher safeguarding inbox (authorised staff), never in the open view or
to peers.

## 6. Rights & non-use
Edit or delete today's entry → honoured. Confirm mood data is **not** used for grading/profiling/advertising.

## Acceptance checklist
- [ ] 100% self-report; 0 inference (SC-001).
- [ ] 100% "classmate" routed to safeguarding only; never peer-visible (SC-002).
- [ ] Consent-gated parent notice for sustained low mood (SC-003).
- [ ] Teacher gets actionable, reviewed recommendations; all actions logged (SC-004).
- [ ] 0 grading/profiling/advertising use (SC-005).
- [ ] Edit/erase honoured 100% (SC-007).
