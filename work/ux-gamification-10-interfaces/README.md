# 10 Interfaces UX Gamifiees (HTML/CSS)

Ce dossier contient 10 propositions d'interfaces avec:

- la meme palette de couleurs LearnEU
- plus de gamification (missions, badges, streaks, leaderboard, boss level, etc.)
- des fichiers HTML statiques faciles a adapter dans les apps existantes

## Palette conservee

- Navy: `#0F1B2D`
- Navy 2: `#1A3658`
- Orange: `#F26334`
- Orange dark: `#D44E22`
- Teal: `#2BB4B8`
- Grey: `#3F4A5A`
- Background: `#F5F7FA`

## Fichiers

- `01-quest-dashboard.html`
- `02-skill-map.html`
- `03-badge-gallery.html`
- `04-streak-arena.html`
- `05-class-leaderboard.html`
- `06-boss-battle-revision.html`
- `07-loot-rewards.html`
- `08-season-pass.html`
- `09-guild-coop.html`
- `10-mission-control-minimal.html`

Ouvre `index.html` pour voir les apercus.
